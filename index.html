    Basis

    • I = Q / t — stroomsterkte (A), lading (C), tijd (s)
    • U = E / Q — spanning (V) is energie per lading
    • U = I · R — wet van Ohm
    • G = 1 / R = I / U — geleidbaarheid (S)
    • R = ρ · ℓ / A — soortelijke weerstand ρ (Ω·m), lengte ℓ (m), doorsnede A (m²)
    • A = ¼ π d² — doorsnede van een ronde draad
    • Lading elektron: e = 1,602·10⁻¹⁹ C

    Vermogen en energie

    • P = U · I = I² · R = U² / R
    • E = P · t — in J (W·s) of kWh (kW·h)
    • 1 kWh = 3,6·10⁶ J
    • η = Pnuttig / Pin = Enuttig / Ein (× 100%)
    • Ez = m · g · h met g = 9,81 m/s²

    Schakelingen

    • Serie: Rv = R₁ + R₂ + …; I overal gelijk; Ubron = U₁ + U₂ + …
    • Parallel: 1/Rv = 1/R₁ + 1/R₂ + …; U overal gelijk; Itot = I₁ + I₂ + …
    • Parallel: Gv = G₁ + G₂ + …; serie: 1/Gv = 1/G₁ + 1/G₂ + …
    • Spanningsdeler: U₁ / U₂ = R₁ / R₂

    Transformator (ideaal)

    • Up / Us = Np / Ns
    • Pp = Ps → Up · Ip = Us · Is
